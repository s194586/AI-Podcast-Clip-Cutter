# Beyond Portfolio MVP

This backlog captures product work intentionally outside the current local-first Portfolio MVP.

## Processing and media intelligence

- Cloud processing instead of local-only compute.
- Cloud transcription and diarization.
- Active-speaker and face tracking.
- Diarization-aware colored subtitles.
- Subtitle editor.
- Improved subtitle styling and transcription quality.

## Product and platform

- Render queue, bulk render, and retry handling.
- Better UX/UI polish across the workflow.
- Authentication and multi-user support.
- Object storage and persistent cloud data.
- Hosting and deployment.

## Operations and efficiency

- Observability and monitoring.
- Performance and cost optimization.
